# Compound Learnings Repository

## Purpose

Track insights, patterns, and reusable components across all projects.

This directory contains organizational knowledge that compounds over time.

## Structure

```
compound/
├── patterns/         # Reusable technical patterns
│   ├── auth/
│   ├── database/
│   ├── api/
│   └── ...
├── decisions/        # Decision evolution over time
├── components/       # Extracted, reusable modules
├── anti-patterns/    # Things that didn't work
├── metrics/          # Performance benchmarks
└── lessons/          # General insights
```

## How to Contribute

1. After completing a project, review what you learned
2. Extract patterns that could be reused
3. Document decisions that changed
4. Update relevant files
